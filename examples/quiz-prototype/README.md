# Quiz UI prototype

Run from this directory:

```sh
python3 -m http.server 8080
```

Then open <http://localhost:8080>.

This is an exploratory UI example, not the production implementation. It captures the first playable flow across all 10 questions. Its code, images, and content details remain disposable review material. Product learnings that should survive a production rewrite—including information-screen copy, duplicate avoidance, guess history, repeated-guess prevention, keyboard behavior, focus treatment, and the Warm Coral color system—are recorded in [`../../docs/product.md`](../../docs/product.md#validated-prototype-learnings).
